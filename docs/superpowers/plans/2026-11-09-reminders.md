# Напоминания — план реализации

**Цель:** разовые напоминания по обычной просьбе в Discord, с сохранением после перезапуска, просмотром и отменой своих заданий.

**Устройство:** отдельная SQLite-база в существующем Docker-томе, три инструмента модели и небольшой фоновый обработчик. Модель разбирает относительный срок или точную дату; код сохраняет задание и отправляет текст без новой генерации. Время без пояса — Москва. Канал и получатель берутся из доверенного события. `/reset` очищает разговор, не задания.

**Границы:** один получатель — автор просьбы; отправка в исходный текстовый канал. Разовые задания, до года вперёд, текст до 500 символов и до 50 активных заданий на участника сервера. Права проверяются при создании и перед отправкой. Повтор одного запроса не создаёт дубликат. Неизвестный результат отправки не повторяется автоматически.

- [x] SQLite-хранилище: сохранение, чтение своих, отмена, атомарный захват задания, статусы, восстановление после сбоя; тесты.
- [x] Инструменты `create_reminder`, `list_reminders`, `cancel_reminder`: строгие параметры, время, права, общий лимит изменений; тесты.
- [x] Обработчик срока: запуск после подключения, отправка с упоминанием только заказчика, безопасные повторы до отправки/после однозначного отказа, сохранение результата; тесты.
- [x] Подключение к `/ask` и флудилке, короткий промпт с текущим временем, документация.
- [x] Сборка и все тесты; независимое ревью; модельные пробы с отдельной временной БД и подменённой отправкой Discord.
- [x] Дополнение пользователя: модерационные изменения доступны только авторам с ролью `1242978551154868326` или `1278077913899597936`, дополнительно к правам Discord; проверка свежих ролей перед записью, включая владельца и Administrator.
- [x] Резервная версия, сборка и запуск контейнера; проверка старой памяти и новой базы. Без коммита и push до отдельной просьбы.

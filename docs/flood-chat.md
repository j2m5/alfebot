# Диалоги во флудилке

Память работает только в канале `1242896006937579522` («🍻-флуд»).

- Обратиться: `/ask`, упоминание бота или ответ (reply) на его сообщение.
- Продолжить конкретный разговор: reply на нужный ответ бота.
- Повторный `/ask` или упоминание без reply подхватывает последний ответ этому пользователю за 30 минут.
- Обычные сообщения записываются локально, без вызова модели. Другие боты и вебхуки игнорируются.
- Запросы из других каналов и лички не получают контекст флудилки.

В модель передаётся небольшой фон: кандидаты из последних 30 сообщений плюс до 8 сообщений выбранной цепочки. Общий предел — 6000 символов; длинные записи сокращаются. Это не поиск по недельному архиву: бот может не помнить тему, которая выпала из контекста.

База `./data/conversations.sqlite` хранится в существующем Docker-томе `/app/data`. Требуется Node.js 22.13+ с `node:sqlite`. SQLite в Node 22 выводит предупреждение ExperimentalWarning, что не мешает работе. История ограничена семью днями и 5000 записями. Очистка выполняется при запуске, при записи и раз в час.

При запуске подхватываются до 40 последних сообщений канала. События редактирования и удаления обновляют память; удаление вопроса удаляет зависимые записи, удаление первого slash-ответа также удаляет сохранённый slash-вопрос. Изменения, произошедшие при выключенном боте, могут остаться незамеченными до истечения срока хранения. Картинки и содержимое вложений не распознаются.

Боту нужны View Channel, Read Message History, Send Messages и включённый Message Content Intent. Дополнительной регистрации slash-команд не требуется.

Для `/ask` и диалогов действует общий лимит: одно обращение одновременно, без очереди. Занятый бот просит повторить вопрос. Дедлайн остаётся 28 секунд, рассуждения отключены, ответы компактные. Фоновый переводчик Dev Tracker использует отдельный промпт и не получает память чата; одновременный перевод может увеличить задержку облака.

Для резервного копирования нужно включать Docker-том целиком (для согласованной копии SQLite остановить контейнер либо использовать SQLite backup API); одного образа недостаточно. В логах диагностики не печатается история сообщений.
